# Method: from a problem to its result

What a project does before it builds and after it finishes, so that the work is not redone and can be resumed. The
shape is the [project shape](../../shapes/project.md).

| Principle | Claim |
|---|---|
| [Specify before building](specify-before-building.md) | the scope is written, in and out, before the work starts |
| [Name the baseline](name-the-baseline.md) | a review is finished when it names what the result is compared with |
| [Leave a trail](leave-a-trail.md) | a job leaves what was asked, found, produced and where it lives |
| [A project is six topics](a-project-is-six-topics.md) | the project is a folder of six parts, each a topic |
