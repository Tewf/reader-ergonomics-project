# Plan

The steps of the first job, what was settled before it began, and what was left to the maintainer.

**Shape:** [topic](https://github.com/Tewf/reader-ergonomics-topic/blob/86e14fe9a1a9877d6a87a2f8b4e8713f98724b5a/shapes/topic.md)

## Steps

1. Frame the problem and list the field's names.
2. Search each name, surveys first, and stop a search string after five results that add no concept.
3. State the best evidence and the evidence against it.
4. Take a position: what is known, what is not found.
5. Name the baseline, then write the findings on the front page.

## Decided first

- The sources: 25 to 40, grey and formal mixed.
- The [grades](../../../evidence/project-method/position.md): measured, supported with caveat, convention, not supported.
- The stop: the review is done when it names the baseline.

## For the person to decide

- Whether the repository keeps its name.
- Whether the comparison with the baseline is run.
- Every push of the work to the public repository.
